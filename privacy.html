Privacy Policy

Last updated: 3 November 2026

IFNOVA Autopilot is a personal tool operated by the owner of the IFNOVA YouTube channel. It is used only with the owner's own Google account.

What data it uses

With the owner's permission, the tool uses the YouTube Data API to upload videos to the owner's channel, set their titles, descriptions, tags, thumbnails, playlists and scheduled publish times, and read the channel's own video information.

What it stores

An OAuth refresh token is stored as an encrypted secret in the owner's private GitHub repository so scheduled uploads can run. No other personal data is collected, stored, sold or shared with third parties.

Google API Services

IFNOVA Autopilot's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. It uses YouTube API Services; see the YouTube Terms of Service and Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
